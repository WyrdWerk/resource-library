API

v1 · read-only · no auth

The same curated catalog this site renders, served as plain JSON over plain GETs — built for scripts and agents, documented for humans. No keys, no accounts; responses carry ETags and per-endpoint cache headers, and cross-origin reads are allowed from anywhere.

Quick start

Search ranks by a fixed lexical score over titles, briefs, taxonomy labels and curated aliases — deterministic, no embeddings. Facet filters are comma-separated lists: OR within a family, AND across families.

# search — 20 per page by default, cursor-paginated
curl "https://cheapinfra-resources.wyrdwerk.com/api/v1/search?q=vector+database"

# CSV facet filters (OR within a family), open-source only
curl "https://cheapinfra-resources.wyrdwerk.com/api/v1/search?topic=ai-inference,quantization&open_source=true"

# date-bounded, title-sorted, trimmed to three fields
curl "https://cheapinfra-resources.wyrdwerk.com/api/v1/search?from=2026-08-01&to=2026-08-31&sort=title&fields=id,title,canonical_url"
