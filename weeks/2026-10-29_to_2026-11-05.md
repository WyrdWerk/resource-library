# #share-tech resources — week of 29 Oct–5 Nov 2026

12 curated resources, newest first.

## Multica
- URL: https://github.com/multica-ai/multica
- Shared by: ROman (31 Oct)
- Categories: ai-tool, github
- Brief: Multica is an open-source, self-hostable platform for humans and AI agents to work as one team, built as a "software factory" where agents collaborate on software work with human oversight. It gives a team a shared workspace for running coding agents together instead of each agent working in isolation, and Tom called out its good UX for that setup while noting he isn't the target market.

## Subvocal
- URL: https://subvocal.company
- Shared by: Tom (31 Oct)
- Categories: ai-tool, web-app
- Brief: Subvocal is a pair of smart glasses from The Subvocal Company that turns silently mouthed speech into text at the speed of voice, so you can type without a keyboard or speaking aloud. The YC Fall 2026 startup says its prototypes reach over 200 words per minute and is taking US reservations for a Q1 2027 ship date. - Warning: the 200-words-per-minute figure is the company's own prototype claim and has not been independently verified; early-bird price is $499 with a refundable $199 deposit, the rest due later.

## Subscription Tier List: How Much API Usage $1 Buys
- URL: https://x.com/adamholtererer/status/2115827734223974762
- Shared by: 0xSaiya (30 Oct)
- Categories: providers
- Brief: Adam Holter's tier list ranks twelve model-and-plan combinations by how much API usage $1 of subscription buys, from Grok 4.7 on X Premium+ ($80) and Claude Opus/Sonnet 5.5 on Claude Max 20x ($66) in S tier down to Gemini 4 Argon on Google AI Pro ($2.8) in F tier, with Claude Haiku 5.5, GPT-5 Astra, Gemini 3.0 Flash and GLM 5.3 in between. It is a quick way to compare which subscription gives the most model usage per dollar across ChatGPT Plus, Claude Max, Google AI Pro, X Premium+ and GLM Coding Pro — presented as a 10-second video, not a page. - Warning: the dollar figures are the author's own and unverified — the video's methodology footnote was not legible, and Yash himself asked for the workings in the thread; some listed model names are unverified. Treat the ranking as one person's comparison, not measured pricing.

## Scheduled Runs
- URL: https://www.affectui.com/components/scheduled-runs
- Shared by: Tom (31 Oct)
- Categories: dev-tool
- Brief: affectUI's Scheduled Runs is a React component that sorts agent tasks into a week of sessions, each with a usage limit — small tasks fill the gaps, big ones split across sessions, and the stack feeds in one card at a time. It shows where queued coding-agent tasks will run before they run, installs via shadcn, and is aimed at coding agents, API quotas, and rate-limited tools. - Warning: part of affectUI Pro (paid) — Alp asked in the channel why he has to pay, and Tom's reply was "you can just ask your ai to copy lol".

## Hex
- URL: https://github.com/anomalyco/hex
- Shared by: thelaggingway (2 Nov)
- Categories: dev-tool, github
- Brief: Hex is local voice dictation for Mac, Windows, and Linux — hold a key, speak, and it pastes the transcription into whatever app you're in. Transcription runs entirely on-device after a first-run model download, it's MIT-licensed, and the sharer notes it's more or less equivalent to Willow's free tier.

## dsh-superagent-prototype
- URL: https://github.com/deepseek-ai/dsh-superagent-prototype
- Shared by: 0xSaiya (1 Nov)
- Categories: ai-tool, github
- Brief: DeepSeek's dsh-superagent is a proactive coding agent for a single GitHub repository that watches for Issues and PRs, takes a first pass at fixes in its own agent session, and answers with a pull request. It only acts when asked or when a rule allows it, and a web panel shows what still needs a person. - Warning: research prototype for reference only, not an official DeepSeek product — the README says it may still contain bugs and is not production-ready software.

## Sparks of Weight-Space Programming
- URL: https://rikiyat.github.io/blog/weight-space-programming/
- Shared by: Alp (3 Nov)
- Categories: article, ai-tool
- Brief: A research write-up showing frontier LLMs can natively read and write neural network weights — well past what humans or conventional algorithms manage. It explores "weight-space programming" as a way of working with models directly in weight space rather than only through text.

## voxl
- URL: https://github.com/tembo/voxl
- Shared by: thelaggingway (4 Nov)
- Categories: dev-tool, github
- Brief: Low-latency desktop streaming for the browser, written in Rust — it streams an X11 display, a Mac screen, or a Windows desktop as H.264 over WebSocket to a small web client that decodes with WebCodecs, with input, clipboard, audio, and file transfer. The project's own benchmarks claim 60 FPS at 12–99 ms median latency on a CPU-only VM versus under 8 FPS for noVNC, and the channel compared it with Moonlight, which one member said handles bidirectional clipboard better.

## Sable
- URL: https://github.com/moonmath-ai/Sable
- Shared by: tom (3 Nov)
- Categories: github, ai-tool
- Brief: Sable (Small-field Argument for Bit-exact LLM Execution) proves that a language model with committed weights produced a given reply, bit for bit — a client can verify every token without the GPU that ran the model. It ships the integer-exact model, a sumcheck-based proof system over the KoalaBear field, and the full paper, and is slated for deployment on Zro's Dolly models.

## millivolt-cli
- URL: https://github.com/hv-V6/millivolt-cli
- Shared by: ROman (5 Nov)
- Categories: dev-tool, github
- Brief: mvctl is a single Go binary that controls, inspects, and shows off a millivolt inference proxy from the terminal: operator-plane controls, KPIs, request logs, and spend attribution, plus a live full-screen dashboard, traffic generator, and load benchmark. A deliberately small subset is proposed upstream as millivolt PR #66; the standalone tool adds the TUI, Docker lifecycle commands, and 74 verified commands.
