## dquickts
- URL: https://github.com/stencil-hq/dquickts
- Shared by: Tom (23 Oct)
- Categories: github, dev-tool
- Brief: dquickts is a QuickJS fork adding durable execution: suspend a running JS program mid-loop, serialize the whole heap to bytes, and resume it in another process. It also runs TypeScript natively (no transpile step), ships a durable REPL whose session survives restarts, and includes Rust bindings. - Warning: brand-new repo (created 19 Oct 2026, ~357 stars); license field shows NOASSERTION.

## python-skills
- URL: https://github.com/1y33/python-skills
- Shared by: cata (23 Oct)
- Categories: github, ai-tool
- Brief: python-skills is a pair of open-source agent skills (plain SKILL.md folders) that teach coding agents to write Python a senior reviewer would approve: typed contracts, bounded waits, specific exceptions, and behavior-preserving refactors with characterization tests. Works in Claude Code, Pi, Codex, Cursor, Gemini CLI, OpenCode, and other skill-reading agents.

## Hemmingway
- URL: https://hemmingway.io/
- Shared by: Aspiring UBI Recipient (25 Oct)
- Categories: ai-tool, web-app
- Brief: Hemmingway is an AI writing tool built around its own Hemmingway-1.5 model, which writes emails, texts, replies and stories meant to read as if a person wrote them. It offers an OpenAI-compatible endpoint for subscribers and a free tier to try without an account or card. - Warning: "passes AI detectors 90% of the time" is the vendor's own test result (GPTZero and other detectors, on its own prompts); the free allowance is small, per the sharer's own follow-up in-channel.

## Popcorn
- URL: https://github.com/software-mansion/popcorn
- Shared by: asx (28 Oct)
- Categories: github, dev-tool
- Brief: Popcorn runs Elixir and Erlang applications in the browser, on a BEAM virtual machine compiled to WebAssembly, with OTP processes, message passing and supervision running on the user's device. JavaScript and Elixir communicate through Popcorn's APIs, and the 1.0 release includes documentation, examples and a Phoenix LiveView-in-the-browser demo.

## Hyperlang
- URL: https://github.com/hyperbob-labs/hyperlang
- Shared by: simply_roo (28 Oct)
- Categories: github, dev-tool
- Brief: Hyperlang runs untrusted Erlang inside an Elixir host on the same BEAM, compiling guest source through a verifier into modules that can call only a frozen stdlib allowlist and host-declared bindings, with every run metered for reductions, heap and wall time. It is aimed at agent systems running partly trusted generated code, tools and per-tenant logic inside the VM instead of in a separate process or microVM. - Warning: brand-new repository (created 26 Oct 2026, 3 commits, 31 stars when collected); the speed and memory figures in the README are the project's own measurements on one shared host.

## Rakazo
- URL: https://rakazo.com/
- Shared by: ROman (28 Oct)
- Categories: ai-tool, web-app
- Brief: Rakazo is an open-source alternative to Grok Bot: persistent AI teammates that run on the user's own computer, each given a job such as inbox management, coding or expense tracking, with Gmail, GitHub, Notion and MCP connections. Bots remember what they learn, wake on schedules or webhooks, delegate to each other, and run on the subscriptions or API keys the user already has.

## Codync
- URL: https://www.codync.dev/
- Shared by: ROman (28 Oct)
- Categories: ai-tool, dev-tool
- Brief: Codync is a free, open-source way to message Claude Code, Codex and 40+ other AI agents as persistent bots from an iPhone, with a Rust host running on the user's own Mac, Windows or Linux machine. Bots keep their chat, memory and folder across fallback agents at usage limits, and the phone reaches the host directly or through an end-to-end encrypted relay, with no account or cloud copy of the work.

## OpenBot
- URL: https://openbot.run/
- Shared by: ROman (28 Oct)
- Categories: ai-tool
- Brief: OpenBot is a free desktop app that runs a team of persistent AI agents on the user's own computer, each with its own instructions, workspace and conversation, using the ChatGPT, Claude, Gemini or Grok plan they already pay for or their own model. Agents hand work to each other, queue tasks and keep their workspace when the provider changes, with all data staying local. - Warning: the source is public under the PolyForm Noncommercial licence — free for noncommercial use, commercial use needs a separate licence; it is not open-source. OpenBot is a development preview, and agents can read and change files, run commands and browse without asking each time.

## Cindy
- URL: https://github.com/makecindy/cindy
- Shared by: thelaggingway (28 Oct)
- Categories: ai-tool, github
- Brief: Cindy is an open-source AI agent that brings Claude Code, Codex and Pi harnesses together in one desktop and mobile client, with sessions, tools and automations shared across a user's computers and phone. The client is free and Apache-2.0 licensed, using subscriptions or API keys the user already has, with an optional hosted service for cloud sync. - Warning: the client connects to Cindy's cloud services by default, and official builds collect usage analytics by default (disableable in Settings); the backend service is a separate repository, not part of this one.
