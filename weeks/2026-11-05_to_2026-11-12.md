# #share-tech resources — week of 5–12 Nov 2026

11 curated resources, newest first.

## chirp
- URL: https://github.com/solst-ice/chirp
- Shared by: simply_roo (6 Nov)
- Categories: dev-tool, github
- Brief: Chirp sends text and small files between devices through sound: one device plays a short burst of tones from its speaker and another decodes it from its microphone, with no network, pairing, or account involved. Three modes trade speed for robustness — FAST at ~320 bit/s, ROBUST for noisy rooms, and a near-ultrasonic INAUDIBLE mode — with Reed–Solomon error correction and a terminal-style spectrum UI; nothing is encrypted, so anyone within earshot can listen.

## Botperch
- URL: https://botperch.com/
- Shared by: thelaggingway (7 Nov)
- Categories: web-app, providers
- Brief: A plain-language guide to hosting AI agents — which cloud sandbox, VM, or server fits the job, what it costs with the AI model included, and the catch — covering 29 providers with sourced prices, feature-by-feature explainers, and a cost calculator that shows its arithmetic. The sharer notes it is still a work in progress. Machine prices were checked 29 Oct 2026 and model prices are medians from TokenWatch, so treat the figures as list-rate illustrations rather than live quotes.

## DS Bot
- URL: https://dsbot.app/
- Shared by: ROman (6 Nov)
- Categories: ai-tool
- Brief: DS Bot is a free, open-source desktop app that runs a team of long-lived bots — each with its own name, role, model, and memory — that split work in group chats, hand jobs to each other, and run scheduled tasks, all local-first with your data staying on your computer. Bots use models you set up on your own quota (a DeepSeek sign-in or other model services), with per-bot access controls and token-usage tracking; it also works as a plugin inside DSH Desktop. The installers are not signed yet, so Windows and macOS need a manual bypass on first open.

## GPUTable
- URL: https://gputable.dev/
- Shared by: thelaggingway (7 Nov)
- Categories: web-app, providers
- Brief: GPUTable tracks live per-GPU hourly rental prices across 35+ cloud providers, refreshed every 5 minutes, with on-demand, spot, and reserved pricing plus a daily price-history index. It covers datacenter GPUs from H100s and B200s down to RTX 3060s, so you can compare the cheapest host for a given card at a glance.

## pi-intercom
- URL: https://github.com/nicobailon/pi-intercom
- Shared by: asx (7 Nov)
- Categories: ai-tool, github
- Brief: Pi Intercom is an extension for the pi coding agent that adds direct 1:1 messaging between pi sessions on the same machine, so a research session can hand findings to an execution session, or a worker can ask its planner a blocking question without losing context. Sessions connect through a tiny local broker with an `intercom` tool and an Alt+M overlay, and it integrates with pi-subagents so delegated children can escalate to their supervisor.

## SAG-Wiki
- URL: https://github.com/Zleap-AI/SAG-Wiki
- Shared by: ROman (10 Nov)
- Categories: ai-tool, github
- Brief: SAG-Wiki is a free, open-source (MIT) knowledge base for people and agents that indexes local files without LLM calls or embeddings, using its SAG2 retrieval method to surface passages and answer questions with citations back to the source. The 14 MB download ships a Tauri desktop app and a `sag` CLI — plus a ready-to-install Skill for Claude Code, Codex, and OpenCode — and indexes a million characters in about 200 ms; deep semantic retrieval and cited Q&A need an embedding/answer model configured.

## s³: Simple Scaling of Swarms via Cooperative Multi-agent RL
- URL: https://arxiv.org/abs/2611.08615
- Shared by: ROman (10 Nov)
- Categories: article
- Brief: s³ is the first multi-agent RL method that trains LLM agent swarms to organise themselves — each agent learns when to work alone, share findings, or read teammates' messages, with no preset roles. With matched training and inference budgets, swarms evaluated with twice as many agents as in training solve over 25× more coordination problems than the strongest baseline, and communicating agents cut repeated work by nearly half in exploration.

## Taalas
- URL: https://taalas.com/
- Shared by: asx (11 Nov)
- Categories: ai-tool
- Brief: Taalas is building a platform that turns any AI model into custom silicon — "Hardcore Models" it claims are 1000x more efficient than running the same model as software, with fine-tuning support and apps written in human language. It was shared as the answer to waiting on ASIC nodes for LLMs; its demo chatbot ChatJimmy runs on the same silicon. - Warning: the 1000x efficiency claim is vendor-reported and unverified.

## ChatJimmy
- URL: https://chatjimmy.ai/
- Shared by: asx (11 Nov)
- Categories: ai-tool, web-app
- Brief: ChatJimmy is Taalas's public demo chatbot — a Llama 3.1 8B model hard-wired into custom silicon, answering at around 17,000 tokens per second so thousands of words appear near-instantly. It is a speed demo rather than a full assistant, with a small context window and accuracy that trails larger models. - Warning: the token rate is vendor-reported; the page itself is client-rendered and shows only a status check to crawlers.

## Qwen4-Max-Preview
- URL: https://www.alibabacloud.com/help/en/model-studio/qwen4-max-preview

## Mach-2-Additive-Medium-GGUF
- URL: https://huggingface.co/SyzygyResearch/Mach-2-Additive-Medium-GGUF
- Shared by: one_phantomic (12 Nov)
- Categories: ai-tool
- Brief: A GGUF build of Mach-2 Additive Medium — Qwen3.8-Flash-Next compressed to 1.70 bits per weight, 26.7 GB of weights plus a 102.4 GB n-gram table — retaining 85–102% of the BF16 model's benchmark scores. It needs the Mach-1 fork of llama.cpp (mainline llama.cpp will not load it), about 105 GB of RAM, and a 32 GB+ GPU. - Warning: the 130 GB download and the fork requirement make this a heavyweight local run; benchmark scores are the publisher's own.
