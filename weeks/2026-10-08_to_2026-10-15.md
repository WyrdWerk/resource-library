## Anatomy
- URL: https://skills.wheresryan.sh/anatomy
- Shared by: Tom (11 Oct)
- Categories: dev-tool
- Brief: A Claude Code skill that turns a one-line idea into an interactive isometric "machine" whose moving parts behave the way the concept does — a hash map becomes a post-office sorting desk, a bloom filter a fruit machine. The skill generates framework-free TypeScript/SVG/HTML (or React for Next.js) and ships with a live collection of 33 figures to play with on the site.

## Open Intelligent UI
- URL: https://github.com/CopilotKit/OpenIntelligentUI
- Shared by: ROman (11 Oct)
- Categories: github, ai-tool
- Brief: Extracted from ROman's share of CopilotKit's 9 Oct announcement video (the video itself isn't a library-format resource, but the announced project is): the open-source alternative to ChatGPT's Intelligent UI — your agent builds interfaces on demand (charts, 3D scenes, maps, calculators, games) inside your own app, via any AG-UI agent and any model. Generated interfaces run in an isolated iframe and can be downloaded as standalone HTML; the default setup asks for OpenAI and TypeSafe API keys.
