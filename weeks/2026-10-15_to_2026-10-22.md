## pokeheartgold
- URL: https://github.com/ctrl-cheeb-del/pokeheartgold
- Shared by: Tom (16 Oct)
- Categories: github
- Brief: A full decompilation of Pokémon HeartGold and SoulSilver — everything in C/C++, both ROMs building byte-for-byte, assembled with LLM agents; the tweeter notes about a month of work and roughly $56k at API prices for 4.1MB of compiled code. A remarkable reverse-engineering reference for ROM hackers and a real-world case study of agent-driven decompilation at scale. - Warning: the cost/time figures are from the announcement tweet; the repo is a fork — pret (upstream) doesn't accept AI-generated code and asks that nothing be sent upstream.

## Handwired
- URL: https://github.com/chenglou/handwired
- Shared by: Tom (15 Oct)
- Categories: github, ai-tool
- Brief: Cheng Lou's new toy project that compiles regular JavaScript — if-else, loops, state — into a neural net: no training, exact outputs matching the JS program, fully differentiable, runnable in a browser without a GPU. Demos include a mini OS transformed into a 9,909-weight network and unfreezing a compiled program's weights to train it in real time. - Warning: brand-new experimental repo (created 15 Oct 2026); the author frames it as "for fun", not production tooling.

## Harness²
- URL: https://github.com/google-research/harness2
- Shared by: ROman (18 Oct)
- Categories: github, ai-tool
- Brief: Google Research's Harness² is a plug-and-play framework for recursive agent harnessing: it iteratively refines an agent's harness — system prompt, tools, memory, skills, subagents — per task through a Propose–Probe–Compose loop while keeping model weights fixed. It supports OpenCode and Codex executors with JobBench, LAB, and WorkBuddy-Bench benchmarks, and ships Apache-2.0 with a no-credentials local demo.
