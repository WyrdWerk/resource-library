## pokeheartgold
- URL: https://github.com/ctrl-cheeb-del/pokeheartgold
- Shared by: Tom (16 Oct)
- Categories: github
- Brief: A full decompilation of Pokémon HeartGold and SoulSilver — everything in C/C++, both ROMs building byte-for-byte, assembled with LLM agents; the tweeter notes about a month of work and roughly $56k at API prices for 4.1MB of compiled code. A remarkable reverse-engineering reference for ROM hackers and a real-world case study of agent-driven decompilation at scale. - Warning: the cost/time figures are from the announcement tweet; the repo is a fork — pret (upstream) doesn't accept AI-generated code and asks that nothing be sent upstream.

## Handwired
- URL: https://github.com/chenglou/handwired
- Shared by: Tom (15 Oct)
- Categories: github, ai-tool
- Brief: Cheng Lou's new toy project that compiles regular JavaScript — if-else, loops, state — into a neural net: no training, exact outputs matching the JS program, fully differentiable, runnable in a browser without a GPU. Demos include a mini OS transformed into a 9,909-weight network and unfreezing a compiled program's weights to train it in real time. - Warning: brand-new experimental repo (created 15 Oct 2026); the author frames it as "for fun", not production tooling.

## herdr-quicklook
- URL: https://github.com/dwarvesf/herdr-quicklook
- Shared by: Tom (16 Oct)
- Categories: github, dev-tool
- Brief: A herdr plugin that Quick-Looks whatever path or URL an agent prints: one key overlays a hint on every openable token on screen, and a letter opens files in a rendered preview popup (markdown via glow, images via chafa, csv via qsv), escalates to the file-viewer, or opens URLs in the browser. Shared in answer to "any cool plugins for herdr" — Tom notes his CEO maintains it. MIT licensed.

## Hy-Memory
- URL: https://github.com/Tencent-Hunyuan/Hy-Memory
- Shared by: ROman (16 Oct)
- Categories: github, ai-tool
- Brief: Tencent Hunyuan's open-source memory engine for LLM agents: a dual-system cognitive memory (hierarchical chat memory, two-layer working/coding memory with a version-evolution diff chain) plus MemHub, a local-first desktop/CLI that unifies memory across Codex, Cursor, Claude Code, and OpenCode. The announcement claims its 3B-active Hy-Memory-30B-A3B model leads MemoryArena by 10.2 points while cutting memory volume ~52%. - Warning: the benchmark claims ("beats Opus 5 at memory", MemoryArena lead) are vendor-reported from the announcement tweet, not independently verified.
