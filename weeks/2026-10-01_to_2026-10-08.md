## ccdeck
- URL: https://ccdeck.dev/
- Shared by: Tom (1 Oct)
- Categories: dev-tool, web-app
- Brief: ccdeck is a free, open-source local dashboard for Claude Code and Codex sessions — live session and tool-call views plus cost tracking. Useful if you run multiple agent sessions and want a single pane of glass.

## Cua Spaces
- URL: https://spaces.cua.ai/
- Shared by: baanish (3 Oct)
- Categories: web-app, ai-tool
- Brief: A free full-desktop Space for every agent — macOS VMs on machines you own or in your own cloud (Apple silicon Macs for macOS Spaces, Docker or Podman for Linux), connectable to Claude Code, Codex, Cursor, Gemini CLI, Cline, Kiro and OpenClaw through the Cua MCP. Its Teleport feature moves an app's whole session (tabs, profile, sign-ins) from your Mac into a Space, with nothing read until you approve and Touch ID gating on sensitive items.

## Battleships
- URL: https://battleships.dev/
- Shared by: thelaggingway (3 Oct)
- Categories: web-app
- Brief: An agent-readable comparison of sandbox, VM and runtime pricing for AI agents — 366 providers priced through one engine with every figure quoted from the source pricing page, published as llms.txt, JSON files and a Node pricing engine. - Categories: article

## hyperiux
- URL: https://vault.hyperiux.com
- Shared by: Tom (4 Oct)
- Categories: dev-tool, web-app
- Brief: Hyperiux Vault is a source-first library of interaction effects for React and Next.js — scroll systems, cursor effects, text reveals, page transitions and WebGL scenes that install as editable code in your own repo via the Hyperiux CLI. ## beste
- URL: https://ui.beste.co
- Shared by: Tom (4 Oct)
- Categories: dev-tool, web-app
- Brief: Beste UI is a collection of production-ready shadcn/tailwind blocks and components — 2189+ blocks (heroes, pricing, testimonials, error pages) and 1326+ smaller pieces, each self-contained and installed with one shadcn CLI command and no runtime dependency.
