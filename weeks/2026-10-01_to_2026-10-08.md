## Kotoba
- URL: https://github.com/hattoriai/kotoba
- Shared by: simply_roo (4 Oct)
- Categories: github, dev-tool
- Brief: Kotoba (言葉, "words") is an open-source rich-text editor for Phoenix LiveView forms built on Lexical — formatting, code blocks, tables, file attachments, @-mentions, live collaboration with per-author undo, and safe HTML/text/Markdown rendering, with documents stored through a `Kotoba.Content` Ecto type. ## React Native Deploy
- URL: https://reactnativefeel.com/deploy
- Shared by: simply_roo (4 Oct)
- Categories: web-app, dev-tool
- Brief: "Unlimited free EAS-compatible builds on GitHub" — `rnd build` / `rnd submit` take the same commands and flags as Expo's eas-cli, reading `eas.json` unchanged, but every build runs as a GitHub Actions workflow in your own repo (signing keys in repo secrets, no Expo account or build queue). Free and unlimited on public repositories; on private repos you pay GitHub's runner minutes ($0.062/min macOS) with no subscription. TestFlight submission and QR-code preview installs included; pricing and eas-cli parity claims are vendor-reported.
