# CheapInfra #share-tech — Resource Library

A curated, browsable archive of developer resources shared in the CheapInfra
Discord server's `#share-tech` channel, collected newest-first, week by week.

- **75 resources** across 4 weekly windows (27 Aug – 24 Sep 2026)
- Live site: GitHub Pages (see repo settings)
- `index.html` — the browsable site (search + category filters)
- `data.json` — the full dataset (title, URL, sharer, date, categories, brief, week)

Collection is read-only; briefs are ~2 sentences each. Claims from announcement
posts are unverified unless independently checked.
