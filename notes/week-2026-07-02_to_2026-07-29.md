### 1. IRIS
- URL: https://github.com/versenilvis/iris
- Posted by: formatme, 29 Jul
- Category: dev-tool, github
- Brief: IRIS (Intelligent Real-time Input Suggestion) is an open-source shell auto-completion tool positioned as the successor to Fig: a single native Go binary that runs purely on TTY — no Electron, GUI, account, or telemetry — rendering suggestion menus inline in the real terminal, over SSH and inside tmux. It indexes your aliases and shell history, supports AI suggestions via API key or local models, and configures via a TOML file with instant reload. No Windows support, and it can conflict with other autosuggestion plugins (zsh-autosuggestions, atuin), which the README says to disable first.

### 4. OptMem
- URL: https://github.com/VictorTaelin/OptMem
- Posted by: Tom, 28 Jul
- Category: ai-tool, github
- Brief: Permanent memory for AI agents by Victor Taelin: the whole integration is a 426-token prompt plus a single dependency-free Python script installed with one curl command. You paste a `## Memory` block into your agent's AGENTS.md/CLAUDE.md, then use `memo wake` (read memory at session start) and `memo note` (record one-liners), plus `nap`, `recall`, `zoom`, and `forget`; storage is an append-only log with a rebuildable binary-tree summary cache (1M memories ≈ 608 MB, wake in 0.03s).

### 5. Content Architecture
- URL: https://www.contentarchitecture.dev/
- Posted by: Tom, 28 Jul
- Category: dev-tool, web-app
- Brief: A commercial, agent-ready Sanity CMS starter kit in Next.js 16 and Astro 7 editions: a page-builder CMS with in-app Studio, visual editing, draft mode, SEO helpers, a seed dataset, and Plop scaffolding. Its differentiator is agentic-coding workflow support — it ships AGENTS.md plus scoped skills, two preconfigured MCP servers (one reads the running dev server, one drives real Chrome for screenshots/traces), an editable llms.txt, and token-light Markdown versions of every page served to agents via content negotiation. One license per buyer covers unlimited personal, commercial, and client projects; it is a paid product, not open source.

### 6. nimbus-lite
- URL: https://github.com/vojtasve-droid/nimbus-lite
- Posted by: Rykuuun, 26 Jul
- Category: ai-tool, github
- Brief: A free, framework-free AI chat UI kit in vanilla HTML/CSS/JS — open index.html and it runs, no build step or dependencies. It includes a full chat layout with sidebar, live token streaming with blinking caret, Markdown plus syntax-highlighted code blocks with copy buttons, a model picker, and light/dark themes with accent colors; it is front-end only, so you bring your own backend (OpenAI, Anthropic, or a local model). The maintainer sells a fuller Nimbus kit ($19) adding citations, reasoning blocks, tool-call chips, and attachments.

### 7. worldmonitor
- URL: https://github.com/koala73/worldmonitor
- Posted by: Rykuuun, 26 Jul
- Category: github, web-app
- Brief: An open-source (AGPL-3.0) real-time global intelligence dashboard: AI-synthesized news briefs, a 3D globe and WebGL flat map, a live Country Instability Index for 31 Tier-1 countries, and cross-stream correlation of military, economic, and disaster signals. It is built for programmatic access too — MCP server, REST API with OpenAPI spec, CLI (`npx worldmonitor`), and Python/Ruby/Go SDKs, with local-AI support via Ollama — and ships as a web app, Tauri desktop binaries, and PWA. AGPL-3.0 copyleft applies, so commercial/SaaS use needs a separate license or AGPL compliance.

### 9. pi-dispatch
- URL: https://github.com/edgehero/pi-dispatch
- Posted by: Tom, 25 Jul
- Category: ai-tool, github
- Brief: Runs the pi coding agent as a self-hosted background service: triggered on demand, on a cron schedule, or by GitHub/GitLab issues, comments, and pull/merge requests, each job executing in a locked-down ephemeral container with a durable queue. It enforces per-job/daily/weekly/monthly spend caps before a single token is spent, and ships a live admin panel with run history, cost insights, and per-trigger spend analytics; MIT-licensed. Note: the bare npm name `pi-dispatch` belongs to an unrelated package — the scoped `@edgehero/pi-dispatch` is the correct install.

### 12. delphitools
- URL: https://tools.rmv.fyi/
- Posted by: Tom, 24 Jul
- Category: dev-tool, web-app

### 13. modly
- URL: https://github.com/lightningpixel/modly
- Posted by: Tom, 24 Jul
- Category: ai-tool, github
- Brief: An open-source desktop app (Windows, Linux, Apple Silicon macOS) that turns a photo or text prompt into a 3D mesh using open-source AI models running entirely on your own GPU — no cloud inference. It ships an extension system for swapping in models like Hunyuan3D 2 and TripoSG, node-based generation workflows, and a CLI so agents and scripts can drive generation headlessly; MIT-licensed, around 7.7k stars.

### 14. img2threejs
- URL: https://github.com/hoainho/img2threejs
- Posted by: Tom, 23 Jul
- Category: ai-tool, github
- Brief: A skill for coding agents (Claude Code, Codex, OpenCode) that rebuilds the object in a reference photo as a code-only, procedural Three.js model — reconstruction-by-code, not photogrammetry or mesh extraction — with a staged sculpting pipeline (blockout → material → lighting → optimization) and vision-review quality gates. It is deliberately token-efficient: deterministic scripts handle validation while model tokens are spent only on visual judgment and code; Apache 2.0, around 16.7k stars, with a live demo gallery.
