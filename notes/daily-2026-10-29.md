## Week: 22–29 Oct 2026

### 1. Rakazo
- URL: https://rakazo.com/
- Posted by: ROman, 28 Oct
- Category: ai-tool, web-app
- Brief: Rakazo is an open-source alternative to Grok Bot: persistent AI teammates that run on the user's own computer, each given a job such as inbox management, coding or expense tracking, with Gmail, GitHub, Notion and MCP connections. Bots remember what they learn, wake on schedules or webhooks, delegate to each other, and run on the subscriptions or API keys the user already has.

### 2. Codync
- URL: https://www.codync.dev/
- Posted by: ROman, 28 Oct
- Category: ai-tool, dev-tool
- Brief: Codync is a free, open-source way to message Claude Code, Codex and 40+ other AI agents as persistent bots from an iPhone, with a Rust host running on the user's own Mac, Windows or Linux machine. Bots keep their chat, memory and folder across fallback agents at usage limits, and the phone reaches the host directly or through an end-to-end encrypted relay, with no account or cloud copy of the work.

### 3. OpenBot
- URL: https://openbot.run/
- Posted by: ROman, 28 Oct
- Category: ai-tool
- Brief: OpenBot is a free desktop app that runs a team of persistent AI agents on the user's own computer, each with its own instructions, workspace and conversation, using the ChatGPT, Claude, Gemini or Grok plan they already pay for or their own model. Agents hand work to each other, queue tasks and keep their workspace when the provider changes, with all data staying local.
- Warning: the source is public under the PolyForm Noncommercial licence — free for noncommercial use, commercial use needs a separate licence; it is not open-source. OpenBot is a development preview, and agents can read and change files, run commands and browse without asking each time.

### 4. Cindy
- URL: https://github.com/makecindy/cindy
- Posted by: thelaggingway, 28 Oct
- Category: ai-tool, github
- Brief: Cindy is an open-source AI agent that brings Claude Code, Codex and Pi harnesses together in one desktop and mobile client, with sessions, tools and automations shared across a user's computers and phone. The client is free and Apache-2.0 licensed, using subscriptions or API keys the user already has, with an optional hosted service for cloud sync.
- Warning: the client connects to Cindy's cloud services by default, and official builds collect usage analytics by default (disableable in Settings); the backend service is a separate repository, not part of this one.
