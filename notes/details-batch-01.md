### roll-as-many-dice-as-the-die-has-sides
- Details: A probability paper on Samuel Chen's blog proving that in the Hog dice game (from CS61A), rolling n dice maximizes the expected turn score for an n-sided die. It derives the expected turn score via the law of total expectation — accounting for the "Sow Sad" rule where any 1 collapses the turn score to 1 — then proves the maximum sits exactly at m = n by analyzing the sign of the marginal gain between rolling m+1 and m dice, with charts showing each curve peaking at m = n for 4-, 6-, and 10-sided dice. A neat, self-contained read if you like seeing a game-theory intuition made rigorous.

### gliner2-5-decide
- Details: Fastino's announcement of GLiNER2.5-Decide, a 340M-parameter open-weight (Apache 2.0) model built for schema-defined structured decision-making. Given text plus a set of typed questions — each with permitted answers, cardinality (single, multi, ordered), and cross-question rules — it returns answers with probabilities, confidence scores, and constraint-feasibility metadata. A constrained decoder evaluates related answers jointly, so decisions stay coherent (e.g., detecting prompt injection forces the safety verdict to `unsafe` rather than contradicting it). It also extracts character-level spans and relations and supports full or LoRA fine-tuning. Deliberately compact and non-generative: ~38ms p50 latency on a V100 GPU, ~167ms on a 48-vCPU CPU, runs locally and in air-gapped environments. Topped its unseen 17-dataset internal benchmark (60.1%) — intent routing, ticket triage, banking, sentiment, news topics — beating 4B-class decoder baselines. Natural fits: model routing, tool calling, browser/computer-use action selection, guardrails, context pruning, and LLM-as-judge.

### bendsr
- Details: BendSR (k3ybladewielder) is a native symbolic-regression implementation built with Bend, Higher Order Company's massively parallel functional language. An evolutionary algorithm breeds expression ASTs concurrently across GPUs/CPUs, and Bend 2's integrated proof checker (LAWS.bend/PROOF.bend) enforces safety invariants — determinism, immutability, numerical safety — during stochastic mutation and crossover, so no division-by-zero or silent NaNs. The cases directory is the fun part: recovering Feynman physics laws, multivariable surfaces, embedded closed-loop control laws for edge devices, interpretable quantitative-finance alpha factors, dynamic-pricing demand curves, GDPR-compliant churn risk scoring, and supply-chain reorder formulas. Runs with `bend src/Main.bend` (CPU) or `bend -c` (GPU); published on Bend Hub as a content-addressed package you can import into your own Bend project. A dataset-loader script converts your CSV/XLSX/Parquet into Bend AST structures. Beyond the algorithm, it is an interesting case study of Bend doing real work plus formal verification of ML-flavored code. MIT.

### security-audit-skill
- Details: Cloudflare's open-source coding-agent skill (23.9k stars) that turns your agent into a security auditor — and the seed of Cloudflare's own vulnerability-discovery harness. It orchestrates a six-phase audit: reconnaissance (architecture, trust boundaries, and input surfaces into architecture.md plus a deterministic coverage-ledger.json), coverage-led hunting with isolated hunters and coverage critics, adversarial candidate validation where a fresh verifier tries to disprove every finding, structured output to findings.json with `confirmed`/`needs_validation`/`rejected` verdicts validated against a schema, independent record verification, and target-neutral reporting (REPORT.md, FINDINGS-DETAIL.md, NEEDS-VALIDATION.md). Attack-class playbooks cover memory safety and binary/kernel targets, LLM prompt injection, web protocol and auth, client-side/DOM, supply chain and CI/release, cloud and IAM, RPC and messaging, resource exhaustion, data isolation, and desktop/mobile IPC. Design principles: only confirm established boundary failures, adversarial validation (the checker is never the finder), severity requires demonstrated impact, defense-in-depth gaps are hardening notes not vulnerabilities, and multiple runs improve coverage. Install with `npx skills add`; needs a tool-using agent with parallel subagents, Node.js, and an OS-enforced sandbox. MIT.

### saving-100tb-of-ram-with-math
- Details: A Cloudflare engineering blog post on how small changes to the consistent-hashing algorithm in the Pingora Backend Router reclaimed over 100TB of RAM globally — on top of 100TB the DNS team shed earlier. The root cause: PBR needed dozens of separate consistent-hash rings (one per feature combination), each holding many hashes per server, ballooning to 6GB of hash structures in some cases. Two fixes: a struct-layout insight (the 32-bit server index was wasteful since PBR will never coordinate 65k+ servers; shrinking to a raw `[u8; 6]` byte array with getters dodged Rust's alignment padding and cut memory 25%), and exact math for the error margin per hash count, showing the last 90,000 hashes bought a minuscule 0.7% reduction — so fewer hashes suffice. The post is also a genuinely good explainer: day-one probability (expected value, standard deviation, coefficient of variation), why 160 hashes per server is the NGINX default, how ketama weighting scales by disk space, and why `#[repr(packed)]` was passed over. Worth reading for any systems engineer — a masterclass in how layout awareness plus a little math saves hardware at scale.

### cloudflare-quick-tunnels
- Details: Cloudflare's Quick Tunnels page — "put localhost on the Internet." One command (`cloudflared tunnel --url http://localhost:8000`) creates a public, encrypted `trycloudflare.com` URL for anything running on your machine: no account, no DNS records, no open ports, ready in seconds. The architecture is outbound-only — cloudflared establishes an encrypted connection to the nearest Cloudflare edge and requests return through it, so your router never accepts inbound traffic. Made for development loops: share previews, receive webhooks, run browser tests, or give a coding agent a real endpoint. JSON output mode (`--output json`) for scripts. Install with your package manager (`brew install cloudflared`); no Cloudflare account required.

### bend
- Details: Bend 2 (bendlang/bend, 23.3k stars, by Victor Taelin's team) — "a fast language that blocks AI mistakes via proof." The pitch is threefold: it runs as fast as C on the CPU and CUDA on the GPU (the entire language runs on the GPU with full memory unification), it checks mathematical proofs orders of magnitude faster than Isabelle/Agda/Lean/Rocq (sub-second checks that take other provers minutes), and it is parallel by default — no threads, no locks, no kernels; split work in two and it spreads across every core. The signature feature is LAWS.bend: declare rules your app must never break ("the sum of all balances must be zero", "players can never pass through solid walls", "winning is impossible"), and the compiler mechanically demands a correctness proof whenever code is edited, making violations impossible — their demo shows an AI merging a wrap-around bug without laws, and being forced to fix it with them. Syntax reads like Python with dependent types. Get started with `curl -fsSL https://bend-lang.com/install.sh | sh`, then tell your agent to `bend guide`, keep important rules in LAWS.bend, and run `bend PROOF.bend` before committing. The limitations list is refreshingly honest: Bend 2 is young (Bend 1 programs don't carry over), annotations are verbose, no Windows, no TLS/HTTP/JSON/regex yet, the compiler is 99% AI-written and not fully audited, and the JS target is single-core. Apache-2.0.

### jev-search
- Details: Jev Search (superagents-lab, 507 stars) — search the web in plain language, with a decision model doing the query understanding. Type the request as you would say it ("Rust async runtimes on Hacker News this month"), and a decision model such as TypeSafe's Jev or Cloudflare's Clef chooses the sources, time range, and search terms, then ranks results returned through Search1API. You get links and snippets with visible relevance scores and editable filters — no generated answers. Under the hood: Google, DuckDuckGo, and Yandex for open web; Hacker News, Reddit, and GitHub combine site-restricted Google with dedicated engines; X, arXiv, YouTube, Wikipedia, IMDb, and WeChat use vertical engines — all called concurrently and streamed as newline-delimited JSON. Deployable to Cloudflare Workers (TanStack Start, React, KV cache, rate limits), installable as a PWA, with a model selector (Jev, Clef, Clef-flash) and fallback provider chains. Built by Search1API as an independent project, not an official TypeSafe product. MIT.

### pi-warden
- Details: pi-warden (DevMortimer, 157 stars) — guardrails for the Pi coding agent that steer instead of interrupt. It enforces your project rules on every write (a `pi-warden.md` rule like "a bare TODO without a ticket reference is a violation", judged in ~250ms by TypeSafe's Jev decision model), holds only hard-to-undo actions before they run (force push, `reset --hard`, `rm -rf`, DROP — measured at 3 holds per 1,000 calls on real sessions), and crucially tells the agent what it got wrong so the agent fixes it without you: unverified "done" claims get sent back to run the tests (76% of fake "done"s became real test runs in the maintainer's 1,168-session field report), repeated failing fixes trigger a request for a new hypothesis, and huge tool outputs get trimmed to what matters. Everything is calibrated on recorded sessions with published eval reports — rules broken went from 6/150 runs to 0/150 with warden on; features that didn't earn their cost (working-memory pruning, stale-result stubs) didn't ship. Install via `pi install npm:pi-warden`, then `/warden enable` and `/warden init`; the offline guards work without a key. MIT.
