## Details

### tov
- Details: Tov is a programming language aimed at coding agents: agents write TypeScript-shaped code with stricter types (separate int and f64, no any/null/==), and the Tov compiler checks it, emits C, and hands that to clang, producing a single native binary. The Rust-written checker returns machine-readable fixes (tov check --json) that an agent can apply itself, and the workflow is designed around an agent install prompt plus llms.txt. The project's own benchmarks claim it beats Rust on several micro-benchmarks (e.g. 242k req/s JSON API vs 216k for axum, 42 ms compiles, 33 KB stripped binaries, 1.6 MB server memory) and a Tov-written screen encoder 5.2x faster than x264 at equal quality — all vendor-reported on an Apple M4 Max, treat as unverified. Works today for CLI programs and web servers on macOS and Linux with Bun/Node APIs and npm packages; Windows, TLS sockets, worker threads and some TypeScript features are not yet supported.

### pi-bolt
- Details: Pi-Bolt is an independent MIT-licensed fork of the Pi coding agent by OpenSec that compiles Pi ahead of time to native machine code via JavaScriptCore's B3 backend, so it launches without parsing or JIT warmup and needs no Node.js or Bun installed. The same Pi commands, sessions, settings, providers and extensions work unchanged; builds exist for Linux x86-64, macOS Apple silicon and Windows x64, plus JIT variants for heavy runtime-loaded plugins. The project's benchmarks (Pi-Bolt 0.8.0 vs Pi 1.1.0 on Bun 1.4.2) claim 2-3x faster startup, about a third of the CPU over a session, and much cheaper long answers/large files — vendor-reported on AMD EPYC 7B13 and Apple M5, treat as unverified. Not affiliated with Pi's authors or Oven. The Discord sharer asked whether anyone had tried it, and a follow-up thread discussed porting effort for fabric compatibility.
