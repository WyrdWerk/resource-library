## Details

### hex
- Details: Hex is a local-first voice dictation app for macOS, Windows, and Linux: hold a shortcut key, speak, release, and the transcription is pasted into whichever app is focused. Transcription runs entirely on-device using a speech model downloaded on first run, so nothing leaves the machine afterwards. It is written in Rust, MIT-licensed, and ships installers for all three platforms plus Homebrew, AUR, Nix, and an install script, with experimental features tucked into a Labs section of the sidebar.

### dsh-superagent-prototype
- Details: dsh-superagent is DeepSeek's research prototype of a proactive coding agent for a single GitHub repository: it listens to GitHub (and optionally Feishu), and when someone allowed asks it for work it opens a work item, works on it in its own agent session and directory, then answers in the original conversation, for example with a pull request. It is designed to take as little human attention as possible, acting only when asked or when a rule the team wrote allows it, and a web panel surfaces whatever still needs a person. It is MIT-licensed and explicitly a research prototype, not an official DeepSeek product; setup is done with a coding agent following SETUP.md.
