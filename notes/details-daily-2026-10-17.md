### capy-ai
- Details: Capy AI is an AI software-engineering product: delegate tasks to parallel coding agents that plan, build, and ship, taking work from task to merged PR. The site lists pricing from $20 to $1000, suggesting tiered plans spanning individuals to teams. Useful for developers who want to run multiple coding agents in parallel rather than driving a single agent session; the "best AI software engineer" claim is vendor marketing and the pricing figures come from the site's own metadata, so both should be treated as unverified until checked against current terms.

### handwired
- Details: Handwired is Cheng Lou's new project that turns regular JavaScript code — if-else, loops, and state — into a neural net: no training, exact outputs matching the JS program, and fully differentiable, all runnable in a browser without a GPU. The README explains the trick: program constructs are expressed as arithmetic (e.g. a comparison becomes ReLU terms), then the +/*/relu primitives are collected into a giant matrix multiplication that can also run on WebGPU. Demos include a small desktop OS transformed into a 9,909-weight, 130-layer network, a gallery where you unfreeze a compiled program's weights and train them in real time, and regex/JSON search over 100,000 documents compiled to WebGPU kernels for massive parallelism. MIT licensed. Useful as a mind-bending experiment at the intersection of programming languages and neural nets, and as a playground for differentiable-programming ideas; it is brand-new (created 15 Oct 2026) and framed by the author as "for fun", not production tooling. (Coverage note: written from web-search coverage of the repo and project site — the tweet itself was not directly fetchable.)

### herdr-quicklook
- Details: herdr-quicklook is a herdr plugin by dwarvesf that Quick-Looks whatever path or URL a coding agent prints in your terminal. One key (prefix+v) overlays a one-letter hint on every openable token on screen; picking a letter opens files in a rendered preview popup (markdown via glow, images via chafa, csv via qsv, json via jq, notebooks and office docs via pandoc), escalates to the file-viewer with one keystroke, opens URLs in the browser, and even resolves a pasted GitHub blob URL to your local checkout at that line. Agent suggestions can also push files to the screen automatically during a working turn. It was shared in #share-tech in answer to "any cool plugins for herdr", and Tom notes his CEO maintains it. MIT licensed. Useful for terminal-centric developers who live in herdr and review agent output all day; it requires herdr >= 0.7.0.

### hy-memory
- Details: Hy-Memory is Tencent Hunyuan's open-source memory engine for LLM agents, shipping as a Python SDK (hy-memory) plus MemHub, a local-first desktop and CLI product. The engine provides three memory scenes: hierarchical long-term cognitive memory for chat (an 8-layer hierarchy from raw dialogues up to schemas and intentions), two-layer fact-and-experience memory for working, and the same two layers plus a version-evolution diff chain for coding. MemHub unifies conversation history and coding traces from user-authorized AI applications (Claude Code, Cursor, Codex, OpenCode, Qwen Code) into a single managed runtime and local data directory, enabling governed cross-application memory recall. The accompanying Hy-Memory-30B-A3B model on Hugging Face was trained via attributed reinforcement learning specifically for high-precision long-term memory extraction. Useful for anyone building long-horizon agents that need persistent, structured memory across sessions and tools. The announcement's benchmark claims (leading MemoryArena by 10.2 points, beating Opus 5 at memory) are vendor-reported from the launch tweet and should be treated as unverified; the repo carries an Apache-2.0 license badge.

### artificial-analysis-models-leaderboard
- Details: The Artificial Analysis models leaderboard is the flagship comparison page of Artificial Analysis, ranking 250+ AI models across intelligence, price, output speed (tokens per second), latency (time to first token), and context window, with per-model links into provider pricing. It was shared in #providers alongside an agent-benchmark cost/score rundown that highlighted MiMo-V2.6-Pro at $0.13/task as "top open weights" and compared coding-agent leaders like Claude Opus 5.5 ($5.98/task) against budget options. Useful as the starting point for model and provider selection: sort by the dimension that matters (intelligence for quality, cost per task for budget) and drill into a model's provider tab to find the cheapest fast host. Benchmark figures update continuously and reflect Artificial Analysis's own harnesses, so treat specific numbers as snapshots.
