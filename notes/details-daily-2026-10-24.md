### dquickts
- Details: dquickts is a fork of Fabrice Bellard's QuickJS embeddable JavaScript engine that adds durable execution: you can pause a running program even in the middle of a for loop, serialize the whole heap to bytes, and resume it later in a different process. It runs TypeScript natively with no transpile step, ships a durable REPL (qjs --drepl FILE) whose session survives restarts, and includes Rust bindings. Use cases: hibernating idle scripts to disk, durable workflows that span hours, time-slicing computation across machines, and warm starts from snapshots. ### python-skills
- Details: python-skills is a pair of open-source agent skills (plain SKILL.md folders) from cata that teach coding agents to write Python a senior reviewer would approve. python-dev covers writing, reviewing, and setting up Python — typed contracts, understandable execution, usable APIs, deliberate extension points, reliable operation. python-refactor does behavior-preserving cleanup: scoped audit, characterization tests first, then small verified steps toward the python-dev patterns, with the repo's formatter, linter, type checker, and tests run after each step. They install via npx skills add, as a Claude Code plugin, a Pi package, or manual copy, and work in Claude Code, Pi, Codex, Cursor, Gemini CLI, OpenCode, and other skill-reading agents. (Coverage note: written from the live README — repo created 23 Oct 2026, MIT license.)

### wally
- Details: Wally is RunAnywhere's cloud inference product: an OpenAI-compatible API (https://inference.runanywhere.ai/v1) serving frontier open models, currently GLM-5.3 Flash (380 tok/s decode), DeepSeek V4.1 Flash (615 tok/s), and MiMo V2.6 Pro (320 tok/s), plus Eve, a decision model that answers yes/no, choice, and score questions with a probability via wally decisions or POST /v1/decisions. Cloud and local are explicit choices — Wally never moves a request between them silently — and production Wally uses zero data retention for prompt and completion bodies. Sign in once with wally account login (Google or GitHub) and point any OpenAI client at the base URL. (Coverage note: written from the live product page — the model lineup and live prices change, and pricing lives in the console behind sign-in.)
