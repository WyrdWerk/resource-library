## Week: 22–29 Oct 2026

### 1. Popcorn
- URL: https://github.com/software-mansion/popcorn
- Posted by: asx, 28 Oct
- Category: github, dev-tool
- Brief: Popcorn runs Elixir and Erlang applications in the browser, on a BEAM virtual machine compiled to WebAssembly, with OTP processes, message passing and supervision running on the user's device. JavaScript and Elixir communicate through Popcorn's APIs, and the 1.0 release includes documentation, examples and a Phoenix LiveView-in-the-browser demo.

### 2. Hyperlang
- URL: https://github.com/hyperbob-labs/hyperlang
- Posted by: simply_roo, 28 Oct
- Category: github, dev-tool
- Brief: Hyperlang runs untrusted Erlang inside an Elixir host on the same BEAM, compiling guest source through a verifier into modules that can call only a frozen stdlib allowlist and host-declared bindings, with every run metered for reductions, heap and wall time. It is aimed at agent systems running partly trusted generated code, tools and per-tenant logic inside the VM instead of in a separate process or microVM.
- Warning: brand-new repository (created 26 Oct 2026, 3 commits, 31 stars when collected); the speed and memory figures in the README are the project's own measurements on one shared host.
