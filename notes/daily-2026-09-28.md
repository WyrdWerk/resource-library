### 15. jevgrep
- URL: https://github.com/dzhng/jevgrep
- Posted by: Tom, 28 Sep (found in #providers)
- Category: ai-tool, dev-tool, github
- Brief: Find code by asking what it does: a CLI (plus an installable agent skill) that uses Jev to judge relevance across folders, files, and declarations, returning relevant files, reading leads, and verbatim source excerpts in one stdout response. Installs with `npm install -g @dzhng/jevgrep`; its own ten-task SWE-bench comparison claims ~30% lower coding-agent cost at equal task success. (~803 stars, MIT.) Cost figures are author-reported and not independently verified.

### 16. rust-llm-tidy
- URL: https://github.com/Sewer56/rust-llm-tidy
- Posted by: Sewer56, 27 Sep (found in #providers)
- Category: dev-tool, github
- Brief: An opinionated linter aimed at LLM-generated code (Rust, C#, Markdown): fix/reorder/visibility/spacing transforms plus read-only lint checks, runnable per-file, on git-changed files, or in CI via a GitHub Action. The author's personal tooling ("largely written by LLMs"); expect opinionated rules, 0 stars. Apache 2.0.
