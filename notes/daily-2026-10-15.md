### 2. code-modernization
- URL: https://github.com/anthropics/claude-plugins-official/tree/main/plugins/code-modernization
- Posted by: asx, 14 Oct (via @dani_avila7's announcement tweet)
- Category: github, ai-tool
- Brief: Anthropic's official Claude Code plugin (v1.0.0) for modernizing legacy codebases: it analyzes the system, extracts business rules, generates an approval-gated plan, rewrites across languages — then proves the new code behaves like the old by running both on identical inputs, inventing edge cases, and deliberately breaking tests to check they catch it.
