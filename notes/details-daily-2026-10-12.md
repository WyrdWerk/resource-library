## Details

### anatomy
- Details: Anatomy is a Claude Code skill that turns a one-line idea into an interactive isometric "machine" whose moving parts behave the way the concept does — a hash map becomes a post-office sorting desk, a bloom filter a fruit machine, the TCP handshake a mail ropeway. Its one rule, written above everything else in SKILL.md, is "The object is the explanation": no boxes, arrows, or floating labels; every figure is dozens to hundreds of small solid parts and every number shown comes from the same model that moves them. You write `/anatomy explain <idea>` with modifiers `interactive` (pointer/keyboard response), `WebGL` (shaders for fire, water, plasma), or `3D` (true depth, slow: hours to build). Output is framework-free TypeScript emitting SVG/HTML, or React components for a Next.js site. The site hosts a live collection of 33 figures, and quality is enforced by screenshot audits and automatic checks — on dense machines an audit proves every overlapping pair draws in the right order.

### open-intelligent-ui
- Details: Open Intelligent UI is CopilotKit's open-source alternative to ChatGPT's Intelligent UI, released 9 Oct 2026: drop it into your own app and your agent answers with generated interfaces on demand — step-by-step algorithm visualizations, Three.js 3D scenes you can rotate, working calculators, games and simulations, trips plotted on a real map, and the agent picking text vs chart vs diagram per answer, all streaming in while it generates. Any agent plugs in through the AG-UI protocol (LangChain Deep Agents by default, swappable for Mastra, Google ADK, Microsoft Agent Framework) and any model can be used. Generated code runs in an isolated iframe restricted to an approved list of CDNs, and any generated interface can be downloaded as a standalone HTML file. Caveats: the default setup asks for OpenAI and TypeSafe API keys in the chat header; setup-effort and capability claims are vendor-reported and unverified.
