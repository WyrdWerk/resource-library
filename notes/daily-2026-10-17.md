- URL: https://github.com/chenglou/handwired
- Posted by: Tom, 15 Oct (via @_chenglou's announcement tweet)
- Category: github, ai-tool
- Brief: Cheng Lou's new toy project that compiles regular JavaScript — if-else, loops, state — into a neural net: no training, exact outputs matching the JS program, fully differentiable, runnable in a browser without a GPU. - URL: https://github.com/dwarvesf/herdr-quicklook
- Posted by: Tom, 16 Oct
- Category: github, dev-tool
- Brief: A herdr plugin that Quick-Looks whatever path or URL an agent prints: one key overlays a hint on every openable token on screen, and a letter opens files in a rendered preview popup (markdown via glow, images via chafa, csv via qsv), escalates to the file-viewer, or opens URLs in the browser.
