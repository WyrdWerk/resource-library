## Details

### sparks-of-weight-space-programming
- Details: A research write-up by Rikiya Takehi and colleagues at MIT CSAIL (published 2 Nov 2026) arguing that frontier LLMs can natively read and write neural network weights. Their model GPT-6 Astra identifies what a network was trained to do just from its raw weights, writes small game-playing networks from scratch that outplay PPO-trained ones, and fixes a reasoning-loop issue in Qwen3.5-0.8B by editing 0.016% of its weights — raising MATH-500 from 7.9% to 48.1% with no training loop involved. The authors call this "Weight-Space Programming": LLMs reasoning about what each part of a network computes and changing the weights directly, instead of relying on small symbolic optimizers like Adam. Figures are the authors' own reported results.

### occupysaas
- Details: OccupySaaS is a protest movement written in code, launched October 2026 and Apache-2.0 licensed: laid-off engineers rebuilding popular SaaS tools as clean-room, open-source, drop-in replacements that you self-host with no per-seat pricing. Each project is rebuilt from public documentation and open standards under a strict firewall — spec writers and builders stay separated, AI implements from the spec alone under human review, and a compatibility lab runs the vendors' own public client SDKs against the replacement server to prove existing code works unchanged. The site frames it as "the software built by the 99% belongs to the 99%" and lists its first releases, method, and FAQ.

### tuxee
- Details: Tuxee is a tiny Debian Linux container (60 MB Docker image, about 20 MB RAM, 1-second startup, core written in Go) with a web interface for file management and persistent terminals that survive logout, aimed at servers and at machines running AI agents. It is also available as a standalone web interface for existing Linux servers, with login as a real Linux user and no configuration needed. The web UI adds workspace tabs, drag-and-resize windows with grid snapping, and GUI apps (Chromium, VS Code) alongside the terminals. The repo has 258 stars and positions itself as "the most convenient Linux for servers and agents".

### abliterated-model-provider-directory
- Details: A directory indexing 19 API providers that serve abliterated and uncensored frontier models, based on a catalog scan dated 31 Oct 2026 covering 89 priced models. Each provider gets a full sheet with models, per-token prices, payment rails, and KYC status, plus a compare view that ranks by workload cost (1M input plus 250K output tokens) — cheapest listed is GLM-5.3 Flash Uncensored at $0.20 via uncensoredllm.ai — and a section on defense cases for who can buy and who gets gated. Four providers are explicit no-KYC and Monero rails are noted as an access path. The sharer warns some listed providers will certainly be suspect, so treat the directory as a comparison starting point and verify any provider yourself before sending it data or money.
