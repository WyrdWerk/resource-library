## Details

### vercel-token-pass
- Details: Vercel Token Pass is a $30/month subscription (early access for Pro teams) that provides $80 in monthly inference credit for the GLM 5.3 and Kimi K3 models, redeemable through the Vercel AI Gateway. It is designed for teams running coding agents (fx, Command Code, Pi) or building personal agents with the Vercel AI SDK: the shared team credit covers requests, zero data retention is enabled by default with inference in the US and EU, and there are no automatic overage charges — requests simply stop when credit runs out until the next billing period. Credit does not roll over. Useful as a predictable, seat-free way to budget inference for agent workloads; pricing, the model lineup, and early-access availability are vendor-reported and should be verified on the changelog page.

### xiaomi-mimo-token-plan
- Details: Xiaomi's Token Plan is a subscription offering for the MiMo model family (mimo-v2.6-pro, mimo-v2.6-flash, plus ASR and TTS models), aimed at AI programming scenarios inside tools like OpenCode, OpenClaw, and Claude Code. Individual plans range from $6/month (4.1B credits, Lite) to $100/month (82B credits, Max), with per-seat team tiers at the same price points; credits are consumed per token with a published conversion table (for example 300 credits per 1M input tokens cache-miss on mimo-v2.6-pro), and off-peak hours (00:00–08:00 Beijing) get a 0.8x consumption coefficient. When a monthly quota is exhausted the service suspends until upgrade or the next period. Useful for pricing MiMo inference for sustained coding-agent use; note that mimo-v2.5 models retire on 21 Oct 2026 per the same page, and all pricing is vendor-reported.
