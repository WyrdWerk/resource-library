## Details

### ego-lite
- Details: Ego (lite) is a browser built for AI agents to run web automation — scraping and automating complex websites, including pages behind logins — positioned as the fastest option for agent-driven browsing, always free with no setup. Its vendor-published benchmarks claim agents complete complex web tasks 47–63% faster than tools like chrome-devtools-cli, agent-browser, browser-harness, and playwright-cli (398s vs 587–648s average), with a 93.5% full success rate and lower token cost. Useful for developers building web-automation agents that need reliable, hands-off browsing; treat the speed, success, and cost figures as vendor benchmarks until independently verified.

### tramme
- Details: tramme is a motion-design studio "directed in words": you describe a film (or feed it a brief, video, or folder of material), pin notes to moments or spots in the frame, and it answers with takes to keep or set aside, refining every keyframe in the atelier. It supports keyframes, a graph editor, 2.5D camera, motion blur, masks and mattes, particles, shaders, frame-by-frame drawing, captions from speech, and a sound library, exporting MP4, transparent video, GIF, or Lottie. Free and open source with desktop apps for Windows, macOS, and Linux; the site links to its GitHub repo. Handy for developers and creators who want AI-assisted motion graphics without a traditional timeline editor.

### refuseless
- Details: Refuseless is an inference provider serving "abliterated" models — GLM 5.3 Abliterated, GLM 5.3 Flash Abliterated, Qwen3.8 Flash Next Abliterated, and DeepSeek V4.1 Flash Abliterated — with refusal behavior removed from the weights, plus the vendor-original non-abliterated DeepSeek V4.1 Flash. It exposes an OpenAI-compatible /v1/chat/completions API billed per million tokens (e.g. $2.00/$3.00 per 1M input/output for GLM 5.3 Abliterated, $0.05/$0.15 for the DeepSeek V4.1 Flash safeguards variant), with cached-input discounts and pay-as-you-go top-ups by card or crypto. Worth knowing if you need uncensored open-weight inference, but the models are uncensored by design and all pricing is vendor-published.

### blackbox-ai
- Details: BlackBox AI is a "secure inference" platform offering a model catalog, a model router, dedicated deployments, and forward-deployed engineering, advertising zero data retention for enterprise workloads. Its DeepSeek V4.1 Flash Fast page lists the higher-throughput DeepSeek variant for coding, reasoning, and agentic workloads at $0.60/$2.40 per 1M input/output tokens with a 1M-token context window and capabilities including reasoning, tool use, implicit caching, vision, and structured output. The site also publishes inference benchmarks plus developer docs with SDKs and quickstarts. Consider it for production inference with data-retention requirements, but verify the zero-retention and performance claims independently.

### baseten
- Details: Baseten is an inference infrastructure provider whose model library serves DeepSeek V4.1 Flash Fast — a speed-optimized DeepSeek v4.1 Flash mixture-of-experts model (552B-parameter backbone, 8B active per token in prefill, 16B in decoding) with a 1M-token context window, multimodal text+image input, and configurable reasoning effort. Its Model API prices the variant at $0.60 input / $0.014 cached input / $2.40 output per 1M tokens, callable through an OpenAI-compatible client, and Baseten lets customers apply OpenAI commitment credits to open models. A solid option for high-throughput long-context inference; pricing and performance figures are vendor-published.
