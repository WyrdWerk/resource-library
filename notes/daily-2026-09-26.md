## Week: 24 Sep–1 Oct 2026

### 1. Railway Changelog #0309: Free VMs without an account
- URL: https://railway.com/changelog/2026-09-25-free-vms-without-an-account#free-vms-without-an-account
- Posted by: baanish, 26 Sep
- Category: article
- Brief: Railway Changelog #0309 opens free Linux VMs with no account: `ssh railway.new` gets a 2 vCPU/2 GB box with coding agents preinstalled, 60 minutes to build and 24 hours to claim it before deletion. The same edition adds request tracing in Priority Boarding (edge-to-database waterfalls with no code changes) and OpenCode on Cloud Agents for persistent agent VMs.

### 2. Orca
- URL: https://www.onorca.dev/
- Posted by: ROman, 26 Sep
- Category: ai-tool, web-app
- Brief: A free, open-source Agent Development Environment (ADE): run Claude Code, Codex, Gemini, Cursor CLI, and other CLI agents in parallel across isolated git worktrees, with a Ghostty-class terminal, in-app diff review, embedded browser, and SSH dev built in. Bring your own subscriptions — agents run side by side without interfering.

### 11. GLiNER2.5-Decide
- URL: https://fastino.ai/blog/gliner-2-5-decide-open-weight-decision-model
- Posted by: Tom, 25 Sep
- Category: article, ai-tool
- Brief: Fastino's 340M-parameter open-weight model for schema-defined decision-making: feed it text plus typed questions and get valid answers with probabilities, confidence scores, and constraint-feasibility metadata. Apache 2.0, CPU-capable, strong on routing/triage/guardrail tasks. Benchmark figures are vendor-reported and not independently verified.

## Providers

### Isoquant
- URL: https://isoquant.ai/
- Posted by: thelaggingway, 25 Sep
- Category: providers
- Brief: A new PAYGO inference provider launching with GLM-5.3-Flash at $0.07/$0.20 per 1M input/output tokens with automatic prompt caching; drop-in OpenAI-compatible API, no top-up fees. Its published benchmarks claim the lowest latency and highest throughput versus Together, CoreWeave, Baseten, Fireworks, and Z.ai. Pricing and benchmark figures are vendor-reported and not independently verified.
