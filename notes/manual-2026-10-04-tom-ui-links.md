### 1. hyperiux
- URL: https://vault.hyperiux.com
- Posted by: Tom, 4 Oct
- Category: dev-tool, web-app
- Brief: Hyperiux Vault is a source-first library of interaction effects for React and Next.js — scroll systems, cursor effects, text reveals, page transitions and WebGL scenes that install as editable code in your own repo via the Hyperiux CLI. The free core includes 50+ effects; Pro unlocks all 150+ with new effects added regularly, and code you have installed stays yours even if you cancel.

### 2. vanta ui
- URL: https://vantaui.com
- Posted by: Tom, 4 Oct
- Category: dev-tool, web-app
- Brief: VantaUI is a UI library built from real products — production-grade site templates, app templates, components, blocks and Figma files for Next.js, React and LLM-assisted builds, from @vanta_ui. ### 3. bencho
- URL: https://bencho.dev
- Posted by: Tom, 4 Oct
- Category: dev-tool, web-app
- Brief: Bencho is a library of interactive React components and micro-interactions — asset swap, heat map, image compare, dynamic island, magnetic select, slide-to-confirm and dozens more — each explorable live and liftable straight into your projects. From @cabralorenzo; a shortcut to polished interactions without building them from scratch.

### 4. obsidian ui

- Category: dev-tool, web-app
- Brief: ObsidianUI is a React and Tailwind CSS component library with an emphasis on motion — featured components and interactive effects you can preview, read the source of, and try directly in your project. ### 5. beste
- URL: https://ui.beste.co
- Posted by: Tom, 4 Oct
- Category: dev-tool, web-app
- Brief: Beste UI is a collection of production-ready shadcn/tailwind blocks and components — 2189+ blocks (heroes, pricing, testimonials, error pages) and 1326+ smaller pieces, each self-contained and installed with one shadcn CLI command and no runtime dependency. Free pieces are MIT-licensed for commercial use; Pro blocks need a Beste UI license, though installed code keeps working if the license lapses.
