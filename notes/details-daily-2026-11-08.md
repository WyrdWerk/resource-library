## Details

### gputable
- Details: GPUTable is a live price board for renting cloud GPUs: it lists per-GPU hourly rates for 35 datacenter and consumer cards — H100, H200, B200, B300, A100, MI300X, RTX 4090, RTX 5090 and more — across 42 providers including Vast.ai, Runpod, Lambda Labs, CoreWeave, AWS, Azure, Google Cloud, and Akash, refreshed every five minutes. Each card shows its cheapest available hourly rate alongside on-demand, spot, and reserved pricing, and the site keeps a daily price-history index so you can see whether a rate is trending up or down. The listed rates are live snapshots from the providers' own pricing pages, so treat them as a comparison starting point and confirm the current price with the host before booking.

### pi-intercom
- Details: Pi Intercom is an extension for the pi coding agent that lets separate pi sessions on the same machine message each other directly — a research session can send findings to an execution session, or a worker can ask its planner a blocking question and wait for the answer in the same turn. Each session with the extension loaded connects to a tiny local broker over local IPC; you pick a recipient by name or session ID from the /intercom overlay (Alt+M) or with the intercom tool, which supports send, ask (blocks until replied), reply, and attachments like code snippets. It covers planner-worker coordination, handing a session over to another, and subagent-to-supervisor escalation — delegated children get a contact_supervisor tool when pi-subagents supplies bridge metadata — and cross-machine coordination over SSH is supported too. Install with pi install npm:pi-intercom; MIT-licensed, about 600 stars. Caveat: messaging is local-machine by default, so sessions on other machines need the SSH transport configured.
