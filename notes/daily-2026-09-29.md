### 18. boxd
- URL: https://boxd.sh/
- Posted by: Tom, 28 Sep (gap-fill)
- Category: dev-tool, web-app
- Brief: Boxd offers "composable computers": persistent KVM dev VMs (2 vCPU, 8 GB RAM, 100 GB disk by default) with live memory forking in under 200ms, snapshots, checkpoints, per-machine HTTPS subdomains, and a CLI/API plus MCP integrations for GitHub, Linear, and Slack — pitched for giving agents root and walking away. Billing is credit-based (about €0.22/h for a default machine per the site; €30 of free credits for new accounts). Pricing figures come from the site and are not independently verified.

### 19. boat
- URL: https://boat.dev/
- Posted by: Tom, 28 Sep (gap-fill)
- Category: dev-tool, web-app
- Brief: Boat sells cloud sandbox VMs for long-running agents: full VMs (Docker, systemd, databases), an integrated desktop/browser, and a CLI (`boat new`, `boat prompt` runs Claude Code or Codex inside), API, and SDKs, with stop/resume snapshots that pause billing. They claim $0.036/h for 4 vCPU / 8 GB RAM on a $20/mo plan ($20 of sandbox time), with a price table pitching themselves well under E2B, Daytona, Modal, and Vercel Sandbox. These price comparisons are the vendor's own and are not independently verified.

### 20. pi-better-skills
- URL: https://github.com/edxeth/pi-better-skills
- Posted by: Rykuuun, 28 Sep (gap-fill)
- Category: dev-tool, github
- Brief: A pi extension that fixes skill ergonomics: skills resolve their bundled files from the skill directory (`$PI_SKILL_DIR` instead of the workspace), each SKILL.md loads whole on first read, and path guidance is injected into the system prompt so authors stop babysitting paths. Installs with `pi install git:github.com/edxeth/pi-better-skills`; ~20 stars, POSIX-only.

### 21. pi-coralbricks-provider
- URL: https://www.npmjs.com/package/pi-coralbricks-provider
- Posted by: Linus Sex Tips, 29 Sep (found in #providers)
- Category: dev-tool
- Brief: An npm package (v1.0.19, by monotykamary — also behind pi-tool-repair and pi-mockdeck in this library) that registers CoralBricks as a provider extension for the pi coding agent: GLM 5.3, GLM 5.3 Flash, and DeepSeek V4.1 Flash through the Coral Inference API. It was shared in a support thread asking whether it uses completions or responses endpoints — check the repo README for the current endpoint behavior.
