## Details

### scheduled-runs
- Details: affectUI's Scheduled Runs is a React component for displaying agent work organized into a week of sessions, where each session has a usage limit. Tasks carry an id, title, usage cost, and optionally an assigned agent; booked tasks pin to a day and session while the rest wait in a stack and get sorted in automatically, with small tasks filling gaps and large ones split across sessions. It is designed for coding agents, API quotas, and rate-limited tools, and for showing people where queued tasks will run before they run. The component installs through shadcn and is part of affectUI Pro, so the full version is paid.

### open-inference
- Details: Open Inference is a San Francisco inference provider that reshapes open models to run fast on accelerators beyond GPUs, reworking attention organization, context selection, and weight storage for each target chip. Its models are served through OpenRouter, where the company points users to see them, and it publishes its engineering as it goes. The public site is minimal — a short about page with contact details and no pricing or docs — so the main way to evaluate it is its OpenRouter listings and community reports, which have been mixed, including a Reddit thread about erratic output from its models.

### codefast
- Details: CodeFast is a Turkish AI API platform that sells packaged access to Claude, GPT, Gemini, Grok, GLM, Kimi, Qwen, NVIDIA, and open-source models, plus image and video generation, from one panel. Packages are bought directly by card or crypto or with pre-loaded balance, and the panel handles API key creation, remaining-limit tracking, service status, and support. Its docs list base URLs, endpoints, and model details, and it offers CLI setup guides for Claude Code, Codex, and OpenCode. The site is in Turkish, and the "unlimited DeepSeek" claim from the Discord share is unverified.

### luoluoai
- Details: luoluoAI is a multi-model API gateway that puts GPT, Claude, and Grok behind one OpenAI-compatible endpoint at api.luoluocoder.com/v1, so existing SDK code works with a base-URL change. Its model plaza lists live per-token prices, advertising steep discounts such as GPT-6 Astra at 0.10x list and Claude Opus 5 at 0.20x, with pay-as-you-go top-ups via Stripe and a console for keys, balance, and usage. It also runs a Discord community where new users can claim free credits. The discount figures are the vendor's own and unverified, and community reception in the CheapInfra thread was mixed.
