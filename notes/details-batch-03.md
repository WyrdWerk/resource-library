### avoid-z-index-whenever-possible
- Details: This 2020 article by Daniel Rotter argues that CSS z-index is the billion-dollar mistake of web development and should be avoided whenever possible. It walks through why escalating z-index values don't scale, explains stacking contexts (why a higher z-index can still lose inside a parent's stacking context), and shows how component-based frameworks like React make the problem worse. ### antidoom-liquid-ai-blog
- Details: Liquid AI blog post "Reducing Doom Loops with Final Token Preference Optimization" tackling repetitive degeneration in reasoning models, where the model repeats a span like "Wait, let me reconsider" until the context window is exhausted. The Antidoom method identifies the exact token that begins a loop and trains the model to prefer coherent alternatives at that single position using Final Token Preference Optimization (FTPO), adapting Antislop, leaving the rest of the distribution largely untouched. On an early LFM2.5-2.6B checkpoint the doom-loop rate fell from 10.2 percent to 1.4 percent with eval scores improving across the board; Qwen3.5-4B dropped from 22.9 percent to 1 percent. ### pi-queue-steer
- Details: pi-queue-steer is a Pi extension by tmustier that adds a Cursor-style visible steering and follow-up timeline for the Pi coding agent. While the agent works you can queue instructions: steering goes into a blue next-turn box delivered at Pi's next safe turn boundary, follow-ups into a yellow after-this-run box beneath it, each lane an independent FIFO queue. Any queued row can be moved into and edited inline with the live Pi editor (cursor, wrapping, paste, autocomplete intact), and special command rows execute /compact or /reload instead of becoming LLM messages. Install via pi install npm:@tmustier/pi-queue-steer; MIT licensed.

### pi-grok
- Details: pi-grok is an xAI Grok OAuth provider for the Pi coding agent, letting you use an x.com Premium or SuperGrok subscription inside Pi with no API keys and no billing setup. You log in once via an OAuth 2.0 device-code flow with PKCE, tokens auto-refresh, and requests route through xAI's CLI chat proxy so they ride your subscription quota instead of billed API credits. It supports grok-4.7, grok-4.7-build-fast, grok-4.6, and grok-4.5 (256k default, 500k extended context windows) with live model discovery, plus /xai-status, /xai-usage, an /xai-privacy coding-data privacy toggle, and an x_search tool that lets any model search X. MIT licensed.

### kimi-vendor-verifier
- Details: Kimi-Vendor-Verifier is Moonshot AI's open-source toolkit for verifying third-party vendors serving Kimi models, so buyers can check a vendor's API actually behaves like Kimi's. It runs inspect-ai benchmarks (OCRBench, MMMU Pro Vision, AIME 2025, the BEAM 1M-token long-term memory benchmark, and the DeepSWE multi-step agent benchmark) alongside pytest pre-flight checks for API parameter constraints, tool-call JSON schema validation, K3 feature contracts, and prompt-token accuracy. The README publishes per-provider K3 evaluation results comparing Moonshot, Fireworks, Baseten, Together, DigitalOcean, Inferact, Nebius, Modal, and RadixArk. MIT licensed; install with uv sync.

### agentic-coding-flywheel-setup
- Details: Agentic Coding Flywheel Setup (ACFS) by Dicklesworthstone bootstraps a fresh Ubuntu VPS into a complete multi-agent AI development environment in about 30 minutes with a single install.sh. It installs compatible AI coding agents, session management (tmux), safety tooling (a destructive-command guard and checksum-verified downloads), and coordination infrastructure including Agent Mail over MCP and the beads issue tracker. A manifest-driven TypeScript generator produces the installer from acfs.manifest.yaml, and the repo ships acfs CLI commands, an interactive TUI onboarding, a learning-hub website, a doctor command with safe auto-fixes, and extensive architecture documentation.

### tailscale-shell
- Details: tailscale-shell by monotykamary is a proxied shell plus exit-node picker for Tailscale userspace networking, built around a single ts command. ts finland (or any country, city, or hostname token) picks a Mullvad or self-hosted exit node and re-running cycles through matches; bare ts drops you into a login shell with ALL_PROXY and HTTPS_PROXY pointed at the local 127.0.0.1:1055 proxy, and ts off clears the exit node. It includes a launchd installer for userspace-networking tailscaled on macOS, SSH/scp/sftp wrappers, a ts doctor diagnostic, and offline tests covering real proxy traffic for curl, Node, Python, Go, and JVM clients. MIT licensed; early release, macOS-focused.

### dory
- Details: Dory is a free and open-source (GPL-3.0) native macOS app billed as the development computer rethought: a local Linux workspace bundling its own Docker 29 engine, Compose, Buildx, one-click k3s Kubernetes, managed Linux desktops (Ubuntu GNOME, Debian or Kali Xfce), and headless Linux servers, all stored in one managed .dorydrive. There is no account, no telemetry, and no paid commercial tier; the UI is native SwiftUI rather than Electron, and it can migrate existing Docker Desktop, OrbStack, Colima, or Rancher Desktop setups. For agent automation it publishes a versioned JSON contract, a stdio MCP server, wait primitives, event streams, and policy-enforced sandbox VMs instead of screen scraping.
