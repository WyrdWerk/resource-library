## Details

### swiftvm
- Details: SwiftVM is a native macOS app that runs macOS and Linux virtual machines from your menu bar, built with Swift and Apple's Virtualization framework — no heavyweight hypervisor UI, no root helper, no kernel extension. Guests set themselves up (macOS installs from Apple with no setup assistant; Ubuntu and Debian from ready-made images in seconds), every machine gets an SSH name so you can `ssh web-server` without looking up addresses, and each machine is a single `.swiftvm` folder with APFS-clone snapshots and duplicates. It also offers suspend/resume to disk, shared folders and clipboard, stable per-machine IP addresses with port forwarding, USB device passthrough, and a `swiftvm` CLI that drives the app so the panel and terminal never disagree. Install via `brew install --cask swiftvm-app/tap/swiftvm`. Free and open source; requires Apple silicon and macOS 27 or newer.

### unlimited-ocr
- Details: Unlimited OCR is Baidu's open-source (MIT) 3B-parameter Mixture-of-Experts OCR model for "one-shot long-horizon" document parsing: with only 500M active params and Reference Sliding Window Attention keeping the KV cache constant, it parses dozens of pages in one forward pass (up to 32K context) instead of page-by-page chunking. It builds on DeepSeek OCR's DeepEncoder (SAM-ViT + CLIP-ViT) with 16x token compression — a 1024x1024 page becomes just 256 visual tokens — and scores 93.23 on OmniDocBench v1.5 (+6.22 over the DeepSeek OCR baseline). The repo (27,000+ stars) supports Transformers, vLLM (official Docker images), and SGLang serving through an OpenAI-compatible API, ships an infer.py batch script for image dirs and PDFs, plus a Hugging Face demo and GGUF/Ollama/llama.cpp variants from the community; weights are MIT-licensed, commercial use OK. Caveats: benchmark scores are vendor-reported and have not been independently verified.

### subq
- Details: SubQ is the inference API from Subquadratic for "SubQ Snap", a multimodal long-context decision model (up to 384K context) positioned for enterprise agentic workflows — structured calls like routing, ranking, classifying, and yes/no decisions that don't need a frontier LLM's deep reasoning, at a fraction of the cost. It runs on a proprietary Subquadratic Sparse Attention architecture instead of transformers, and the homepage advertises free 100M tokens for the first 10,000 users, with an OpenAI-compatible API path. Caveats: the company appears to have pivoted its offering — community members noted the homepage no longer features its earlier main LLM (a Qwen-based model) — so verify what's actually on offer before committing; data retention is indefinite by default, with zero-data-retention available only via email request; benchmark and pricing claims are vendor-reported.
